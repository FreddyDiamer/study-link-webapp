# Инвентаризация UI и функционала (ветка `main`)

Полное описание того, **что сейчас реально показывается на экране** в ветке `main`, — исходный материал
для дизайн-системы. Документ описывает фактическое состояние, а не целевое: он фиксирует и работающие
экраны, и заглушки, и визуальные расхождения.

Класс доверия: `reference`. При расхождении с кодом — прав код; документ обновляется в том же коммите,
что и UI.

Связанные документы: [CLAUDE.md](../CLAUDE.md) · [conventions/STYLES.md](conventions/STYLES.md) ·
[conventions/ARCHITECTURE.md](conventions/ARCHITECTURE.md)

## 1. Рамка продукта

**Study Link** — Telegram Mini App, маркетплейс репетиторства. Внутри приложения две роли-«флоу»,
переключаемые в рантайме и сохраняемые в `localStorage` (`currentFlow`):

| Флоу | Акцентный цвет | Namespace роутов | Смысл |
| --- | --- | --- | --- |
| `student` | `telegram-accent` `#64B5F6` | `/student/*` | Ищет репетитора: создаёт заявки, откликается на услуги |
| `tutor` | `telegram-success` `#48BB78` | `/tutor/*` | Продаёт услуги: публикует услуги, откликается на заявки |

Флоу выставляет на корневом `<div>` класс `flow-student` / `flow-tutor`, который переопределяет
CSS-переменную `--custom-primary` (её использует `.btn-primary`). Всё остальное окрашивается вручную
через `:class` на каждой странице.

Сущности домена (`src/shared/types/index.ts`):

| Сущность | Кто создаёт | Статусы |
| --- | --- | --- |
| **Service** (услуга) | репетитор | `ACTIVE` / `INACTIVE` / `SUSPENDED` |
| **Request** (заявка) | студент | в типе статуса нет; в UI рисуют `OPEN` / `MATCHED` / `CLOSED` / `CANCELLED` |
| **ServiceResponse** (отклик студента на услугу) | студент | `PENDING` / `ACCEPTED` / `REJECTED` / `EXPIRED` |
| **RequestResponse** (отклик репетитора на заявку) | репетитор | те же четыре |
| **Deal** (сделка) | система из принятого отклика | `PENDING` → `ACCEPTED` → `IN_PROGRESS` → `COMPLETED` / `CANCELLED` |
| **Review** (отзыв) | обе стороны по сделке | — (рейтинг 1–5, `targetRole`) |
| Справочники: **Subject**, **Teacher**, **Group**, **TeacherSubject** | админ/бэкенд | грузятся один раз в `education` store |

Весь пользовательский текст — русский. Цены — рубли (в `types` остались комментарии «в копейках» —
устаревшие).

## 2. Дизайн-токены, которые сейчас в коде

Источники: `tailwind.config.js`, `src/assets/base.css`, `src/assets/main.css`.

### Цвета (`telegram-*`, тёмная тема, единственная)

| Токен | HEX | Где используется |
| --- | --- | --- |
| `bg` | `#17212B` | фон всех экранов |
| `secondary` | `#242F3D` | подложки, треки табов, «пустые» кружки |
| `card` | `#1E2832` | карточки, шапка, нижняя навигация, дропдауны |
| `input` | `#1A252F` | фон полей ввода (класс `.input`) |
| `border` | `#2C3E50` | все границы |
| `text` | `#FFFFFF` | основной текст |
| `textSecondary` | `#8E9297` | вторичный текст, плейсхолдеры, неактивные иконки |
| `accent` | `#64B5F6` | акцент студента, ссылки, активная навигация |
| `button` / `buttonHover` | `#2AABEE` / `#229ED9` | градиенты, часть спиннеров |
| `success` | `#48BB78` | акцент репетитора, «успешные» статусы, цены |
| `warning` | `#ED8936` | почти не используется |
| `destructive` | `#E53E3E` | ошибки, удаление |
| `gradient.from/to` | `#667eea` / `#764ba2` | `.card-gradient` (не используется на экранах) |
| `custom.primary/secondary` | CSS-переменные | подставляются флоу-классом |

Плюс — стихийно используемая палитра Tailwind по умолчанию: `bg-green-100 text-green-700`,
`bg-yellow-500/20 text-yellow-600`, `bg-red-50`, `bg-purple-500`, `text-yellow-500` (звёзды),
градиенты `from-blue-500 via-purple-500 to-pink-500` и `from-emerald-500 via-teal-500 to-cyan-500`
(блоки обратной связи в профилях). Светлые пилюли (`bg-*-50/100`) на тёмном фоне — прямое
расхождение с темой.

### Типографика

- Шрифт: `Inter` → `SF Pro Display` → системные.
- Шкала стандартная Tailwind (`xs` 12 → `3xl` 30), задана явно в конфиге.
- Фактическое применение: заголовок страницы — то `text-2xl font-bold`, то `text-xl font-semibold`;
  заголовок секции — `text-lg font-semibold`; заголовок карточки — `font-semibold` / `text-lg` /
  `text-xl`; подписи — `text-sm text-telegram-textSecondary`, микроподписи — `text-xs`.
  Единой семантической шкалы (title/subtitle/body/caption/price) нет.

### Форма и глубина

- Радиусы: `rounded-lg` (кнопки-иконки, чипы), `rounded-xl` (кнопки, поля, дропдауны, табы),
  `rounded-2xl` (карточка `.card`), `rounded-full` (пилюли статусов, аватары, бейджи).
- Тени: `shadow-telegram`, `shadow-card`, `shadow-card-hover` — есть в конфиге; в UI встречаются также
  `shadow-lg`, `shadow-xl`, `shadow-2xl`.
- Отступы: экран — `p-4 pt-6` (или `p-4` + `pt-14` от фиксированной шапки), вертикальные интервалы —
  `space-y-3` / `space-y-4` / `gap-6`.

### Анимации

`animate-fade-in`, `animate-slide-up`, `animate-bounce-subtle` (конфиг) + локальные копии тех же
keyframes внутри `WelcomeView.vue`. Плюс `transition-colors/transform duration-200`, `animate-pulse`
(бейдж «+N новых», скелетоны), `animate-spin` (спиннеры).

### Готовые классы-компоненты (`main.css`, `@layer components`)

`.btn`, `.btn-primary`, `.btn-secondary`, `.btn-ghost`, `.card`, `.card-hover`, `.card-gradient`,
`.input`, `.nav-item`, `.badge`, `.badge-success/warning/error`, `.animate-enter`, `.animate-slide`.
Из них реально используются `.btn*`, `.card*`, `.input`; `.nav-item` и `.badge*` — мёртвые
(навигация и пилюли статусов везде свёрстаны inline).

## 3. UI-kit (`src/shared/components/ui`)

| Компонент | Пропсы | Варианты и поведение |
| --- | --- | --- |
| **Button** | `variant` (`primary`/`secondary`/`ghost`/`destructive`), `size` (`sm`/`md`/`lg`), `disabled`, `loading` | Классы `.btn*` + размеры. Слева всегда отрендерен `Loader` в контейнере нулевой ширины: при `loading` он просто проявляется через `opacity`, ширина кнопки не меняется. `destructive` собран inline (`bg-telegram-destructive`), а не классом. |
| **Card** | `variant` (`default`/`gradient`/`hover`), `padding` (`sm`/`md`/`lg`) | База `.card` (уже содержит `p-4`, `rounded-2xl`, границу и тень). На практике почти каждый вызов передаёт свой `class="p-4"`/`p-6`, конфликтуя с внутренним паддингом. |
| **Input** | `modelValue`, `type` (text/email/password/number/tel/date), `label`, `placeholder`, `disabled`, `required`, `error` | Слоты `prepend` / `append` (иконки внутри поля), метка с красной `*`, текст ошибки под полем. `id` генерируется `Math.random()` в `computed` — нестабилен между рендерами. |
| **Select** | `modelValue` (`SelectOption`), `value` (`string`), `options`, `label`, `placeholder`, `disabled`, `required`, `error` | Не нативный селект, а комбобокс на базе `Input`: поиск по подстроке с подсветкой совпадения (`<mark>`), клавиатурная навигация (↑/↓/Enter/Esc/Tab), псевдо-опция «Отменить выбор», состояние «Ничего не найдено» с иконкой лупы, стрелка-шеврон с поворотом. Две модели (`v-model` и `v-model:value`) используются вперемешку по проекту. |
| **Modal** | `modelValue`, `title`, `maxWidth` (`sm`…`xl`), `closable` | `Teleport` в `body`, затемнение `bg-black/50`, две вложенные анимации (фейд оверлея + масштаб окна), шапка с крестиком, слот контента, опциональный слот `footer` с верхней границей. Скролл фона не блокируется. |
| **Loader** | — | SVG-спиннер `animate-spin`, наследует `currentColor` и размер от класса. |
| **Rating** | `rating`, `reviewsCount`, `size` (`sm`/`md`/`lg`), `showCount`, `readonly` | 5 звёзд (полная/половина/пустая), `text-yellow-400` против `text-gray-300`, справа число `4.9` и `(43)`. `cursor-pointer` стоит и в режиме `readonly`. |

**Иконки** (`shared/components/icons`, барель `index.ts`): `StudentIcon`, `TutorIcon`, `ArrowIcon`,
`HomeIcon`, `ServiceIcon`, `OrderIcon`, `ProfileIcon`, `PlusIcon`, `GroupIcon`, `InfoIcon`,
`ContactIcon`, `LoupeIcon`, `FilterIcon`. Все — `stroke="currentColor"`, размер задаётся классом.
При этом большая часть иконок на экранах — **не** из этого набора, а инлайновые `<svg>` прямо в
шаблонах (десятки повторов одних и тех же путей: стрелка-шеврон, лупа, книга, звезда, корзина).

## 4. Оболочка приложения

```

│ AppHeader  (fixed, h-14, bg card)        │
├──────────────────────────────────────────┤
│ <main class="flex-1 overflow-auto pt-14">│
│           RouterView                     │
```

**AppHeader** — логотип (квадрат 32×32 в цвет флоу + иконка «выпускная шапка») и надпись `KAI`
(клик → главная текущего флоу); переключатель роли — кнопка-«призрак» с иконкой, подписью
«Студент»/«Репетитор» и шевроном, раскрывающая дропдаун на 192px с двумя строками
(«Студент · Ищу репетитора», «Репетитор · Предлагаю услуги»); аватар-инициалы 36×36 в цвет флоу.
Клик по аватару всегда ведёт на **профиль студента**, даже во флоу репетитора.

**BottomNav** — четыре элемента, иконка + подпись, активный красится в цвет флоу и утолщает штрих
(`stroke-width` 2 → 2.5). Скрыта, пока роль не выбрана.

| Студент | Репетитор |
| --- | --- |
| Главная · Услуги · Мои заказы · Профиль | Главная · Заказы · Мои услуги · Профиль |

У пункта «Мои заказы» бейдж со счётчиком **захардкожен числом 2** (красный кружок 16×16, `9+` при
переполнении).

**Старт приложения** (`App.vue`): `authService.loginWithTelegram(initData || MOCK_INIT_DATA)` →
`educationStore.initialize()`. Флаг `loading` в компоненте есть, но в шаблоне не используется —
**глобального экрана загрузки нет**, экраны появляются сразу и грузят себя сами.

### 5.1 Welcome `/`

Градиентная шапка (`accent → button`) с «подпрыгивающим» логотипом 96×96, заголовком «Добро
пожаловать!» и подзаголовком. Ниже — две крупные карточки выбора роли (иконка 56×56 с градиентом,
заголовок «Я студент» / «Я репетитор», описание, круглый шеврон), при наведении подсвечивается
граница и карточка масштабируется. Внизу — карточка «Почему выбирают нас?» с тремя пунктами
(зелёная галочка + заголовок + пояснение): знание требований преподавателей, быстрый поиск,
безопасные платежи. Появление элементов анимировано с задержками 0/200/300/500 мс.
Выбор роли → `appStore.setFlow()` → редирект в `/student` или `/tutor`.

### 5.2 Флоу студента

**Главная `/student`.**
1. `SelectGroupCard` — карточка с левой акцентной полосой: заголовок «Укажите вашу группу», подсказка
   в блоке с `InfoIcon`, `Select` со списком групп (загрузка через `educationApi.getGroups()`),
   кнопка «Сохранить группу» (с галочкой) и текстовая кнопка «Больше не показывать»
   (`appStore.showGroupCard`). Показывается, пока у пользователя нет группы или флаг не снят.
2. Карточка поиска: `Input` + кнопка «Найти услугу» → `/student/services?search=…`.
3. Секция «Быстрые действия» (`QuickActions`) — две карточки-строки с цветным квадратом-иконкой:
   «Создать заявку» и «Мои заявки». Третья («Найти репетиторов») закомментирована.
4. Секция «Мои предметы» — **полностью закомментирована** (вместе с моками, генерировавшими
   количество репетиторов/услуг/среднюю цену).

Состояния: спиннер «Загрузка данных...», ошибка с кнопкой «Попробовать снова», контент.

**Каталог услуг `/student/services`.**
Шапка: кнопка «назад», заголовок («Все услуги» или «Услуги по …»), подпись «N услуг найдено»,
кнопка-фильтр справа. Ниже — карточка поиска с `LoupeIcon`. Раскрываемая панель фильтров: `Select`
«Предмет», `Select` «Преподаватель», два `Select` в сетке 2×1 — «Сортировать» (рейтинг/цена/опыт/дата)
и «Порядок»; кнопка «Сбросить».
Карточка услуги: предмет + имя преподавателя, цена справа акцентом, блок преподавателя (аватар-инициалы
40×40, число услуг, звезда + рейтинг + отзывы), описание (обрезка 5 строк), кнопка «Оставить заявку».
Часть полей карточки — заглушки маппинга: опыт `0`, рейтинг `0`, отзывов `0`, формат «онлайн»,
доступность «свободен». Клик по карточке ничего не открывает (только `console.log`).
Состояния: спиннер «Загрузка услуг...», ошибка + «Попробовать снова», пустое состояние
(круг с иконкой, «Услуги не найдены», «Сбросить фильтры»).

**Модалка «Оставить заявку»** (`RequestModal`, maxWidth `lg`): плашка с названием услуги, репетитором
и ценой; `textarea` «Что именно нужно?» с подсказкой; `Select` «Бюджет» (цена услуги / готов обсудить /
ищу дешевле / готов доплатить); `Select` «Когда нужно?» (сегодня/завтра/на неделе/в течение месяца);
кнопки «Отменить» и «Отправить заявку»; сноска-пояснение. Результат — `createServiceResponse` +
Telegram-алерт.

**«Мои дела» `/student/orders`.**
Заголовок «Мои дела», подпись «Заявки, отклики и активные уроки». Табы-сегменты (подложка
`telegram-secondary`, активный — «карточка» `telegram-card`) с эмодзи: 📋 Заявки · 📤 Отклики ·
🟢 Активные. Данные догружаются при переключении, между ними — спиннер.

- **Заявки** (`RequestsList`): пунктирная карточка-CTA «Создать заявку» сверху; затем карточки
  «Предмет • Преподаватель», «до N₽» зелёным, описание, «Создана» (относительная дата) и «Откликов»
  с числом и красным бейджем новых. Клик → детали. Кнопка редактирования закомментирована.
  Пусто: круг с иконкой, «У вас пока нет заявок», кнопка «Создать заявку».
- **Отклики** (`ResponsesList`): карточки «Предмет • Преподаватель», имя репетитора со звездой и
  рейтингом, пилюля статуса (Ожидает ответа / Принят / Отклонён / Истёк), дата, текст сообщения,
  строка «Моя цена / Цена услуги / Дедлайн»; внизу кнопка-призрак «Найти ещё услуги». Клик по
  карточке — заглушка. Пусто: «У вас пока нет откликов» + «Найти услуги».
- **Активные** (`DealsList`): карточки сделок — «Предмет • Преподаватель», репетитор + рейтинг,
  пилюля статуса (Ожидает подтверждения / Принята / В процессе / Завершена / Отменена), цена,
  строка «Источник: отклик на услугу | на заявку», дедлайн или дата создания, кнопка
  «Начать»/«Продолжить» для `ACCEPTED`/`IN_PROGRESS` (заглушка); внизу «Найти ещё репетиторов».
  Пусто: «У вас пока нет активных уроков» + «Найти репетитора».

**Создание заявки `/student/orders/create`.**
Отдельная шапка (`card` + нижняя граница) с кнопкой «назад» и заголовком. Форма — пять карточек-секций,
каждая с заголовком и пояснением: «Предмет» (`Select`, опция «Другое» закомментирована),
«Преподаватель» (необязательный `Select`), «Описание задач» (`textarea` высотой 160px с классом
`.input`), «Срок выполнения» (`Select`: День / Неделя / До конца семестра / Выбрать день → `Input[date]`),
«Бюджет за занятие» (`Input[number]` + знак ₽). Внизу кнопка `size="lg"` на всю ширину «Создать заявку»,
задизейбленная до валидности. Ошибки полей не показываются — только `disabled` и Telegram-алерт при сбое.

**Детали заказа `/student/orders/:id`.**
Шапка с кнопкой «назад» и заголовком «Детали заказа» (кнопка «Редактировать» закомментирована).
Карточка заказа: предмет, бюджет справа с подписью «бюджет», строки «Преподаватель / Срок / Создан»,

## 7. Статусы и их визуализация

| Сущность | Значение | Подпись в UI | Как окрашивается |
| --- | --- | --- | --- |
| Заявка | `OPEN` | Открыта | зелёный (в одном месте — светлый `bg-green-100`) |
| | `MATCHED` | Найден репетитор | синий |
| | `CLOSED` | Закрыта | серый |
| | `CANCELLED` | Отменена | красный |
| Услуга | `ACTIVE` | Активна / Активно | зелёный |
| | `INACTIVE` | Неактивно / Заморожена | серый / жёлтый |
| | `SUSPENDED` | Приостановлено | красный |
| Отклик | `PENDING` | Ожидает / Ожидает ответа | оранжевый или жёлтый |
| | `ACCEPTED` | Принят | зелёный |
| | `REJECTED` | Отклонён | красный |
| | `EXPIRED` | Истёк / Истёк срок | серый |
| Сделка | `PENDING` | Ожидает / Ожидает подтверждения | оранжевый или жёлтый |
| | `ACCEPTED` | Принята / Принят | синий |
| | `IN_PROGRESS` | В процессе / В работе | зелёный или акцентный |
| | `COMPLETED` | Завершена / Завершён | серый |
| | `CANCELLED` | Отменена / Отменён | красный |
| Срочность | `LOW`/`MEDIUM`/`HIGH` | Низкая/Средняя/Высокая, в одном месте — Не срочно/Средняя/Срочно | зелёный/жёлтый/красный |

Одна и та же сущность в разных местах получает разные подписи, разные оттенки и разную форму пилюли —
это первое, что имеет смысл унифицировать в дизайн-системе (`StatusBadge` + единый словарь статусов).

## 8. Форматирование данных

В `src/shared/utils/formatters.ts` есть `formatPrice`, `formatDate`, `formatDateTime`,
`formatRelativeTime`, `formatUserName`, `formatRating`, `truncateText`. На экранах они практически не
используются: почти каждый файл объявляет собственные `formatPrice` / `formatDate` / `formatDeadline`.

Фактические форматы:

- **Цена:** `2200 ₽`, `2200₽`, `до 2200₽`, `2 200 ₽/час`, `220000₽` (мок в копейках) — единого нет.
- **Дата:** `15.01.2024`, `15 янв`, `15 января 2024 г., 10:30`.
- **Относительное время:** «Только что», «N ч. назад», «Вчера», затем `15 янв`.
- **Дедлайн:** «Просрочен», «Скоро», «Через N ч.», «Завтра», затем `15 янв, 18:00`.
- **Рейтинг:** `4.9` + `(43)`; там, где данных нет, печатаются нули или `—`.

## 11. Сводка расхождений, важных для дизайн-системы

1. **Нет единой шкалы типографики и отступов** — заголовки экранов и карточек оформляются по-разному.
2. **Светлая палитра Tailwind просачивается в тёмную тему** (`bg-green-100`, `bg-yellow-50`,
   `bg-gray-100`, `text-gray-300` в звёздах) — на `#17212B` это выглядит инородно.
3. **Статусы, пустые состояния, спиннеры, шапки и табы дублируются** десятками копий вместо
   компонентов.
4. **UI-kit неполон**: нет `Textarea`, `Tabs`, `Badge`/`StatusBadge`, `Avatar`, `EmptyState`,
   `PageHeader`, `Spinner`; при этом `EmptyState` и фильтры уже написаны, но не подключены.
5. **`Card` конфликтует сам с собой** — базовый `.card` уже задаёт `p-4`, а вызовы передают свой
   паддинг классом.
6. **Иконки живут в двух системах** — барель `icons/` и десятки инлайновых `<svg>`.
7. **Три экрана работают на моках** (`/student/orders/:id/edit`, `/tutor/services`,
   `/tutor/services/:id/responses`) — их макеты нельзя считать отражением реальных данных.
8. **Цены и даты форматируются локально** в каждом файле, общие форматтеры простаивают.
9. **Флоу окрашивается вручную**: `--custom-primary` покрывает только `.btn-primary`, всё остальное —
   ручные `:class` с `telegram-accent` / `telegram-success`.
10. **Нет состояний фокуса и доступности**: `focus:outline-none` без замены, `cursor-pointer` на
    неинтерактивных элементах, `aria-*` не используются.
